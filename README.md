# Bobcat Brawl

A retro punch-and-kick fighting game starring the Mary Bragg crew: Jaiden, Ava, Linus, Bobcat, Dom, Audrey and Ayla.

## Play

Open the game link on any phone or computer. To add it to your home screen like an app:

- **iPhone (Safari):** tap Share, then **Add to Home Screen**
- **Android (Chrome):** tap the ⋮ menu, then **Install app** (or **Add to Home screen**)

Once installed, it works offline.

## Controls

| Action | Phone | Keyboard |
|---|---|---|
| Move | ◀ ▶ | ← → |
| Jump | ▲ JUMP | ↑ or Space |
| Punch | PUNCH | Z |
| Kick | KICK | X |
| Block | Hold away from your opponent | Hold away from your opponent |

Best of three rounds against the computer.
